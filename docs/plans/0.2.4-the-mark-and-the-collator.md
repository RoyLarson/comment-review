# 0.2.4 -- the mark, the revise, and the collator

**The middle.** A role hands back marks; something checks each one against the page it rules on,
reconciles what several roles said about one place, emits a conflict for the ones that disagree, and
**pulls a revise so the next stage reads what the last one settled.**

**Branch:** `feat/the-mark-and-the-collator`, off `feat/0.2.4-what-a-reviewer-is-handed`.

**Done:** every box below ticked. A stranger runs one command per stage over a filled sheet and gets
a revise plus a diff for every conflict, with every number here re-derivable from the round-2 marks
in [`evidence/the-loop-measured-2026-08-27/`](../../evidence/the-loop-measured-2026-08-27/).

## The shape this plan is written against

```
                 ORIGINAL  (--repo .)
                      |
   enriching stage    |   facts -> into the next binder. No docket, no revise
                      v
   stage 1  ownership-context          sheet -> marks
                      |                 verify -> reconcile -> revise step -> docket
                      v                 proof_setter --out revise-1  +  prove_unchanged
                 REVISE 1  (a tree copy, the drafts overlaid)
                      |                 ASSERT the address set equals the original's
                      v
   stage 2  block / function / module, one message, blind to each other
                      |                 same four steps
                      v
                 REVISE 2   ==   the draft the human approves at 7a
```

Every editorial boundary is the same four steps -- **verify, reconcile, revise, pull** -- and the
last one's output is what 7a reads. No separate backward phase; no stage is re-entered.
`Process: #34`.

| | holds because |
| --- | --- |
| **the address space never moves** | `prove_unchanged` holds the code byte-identical, and a place is determined by CODE. Gated by re-censusing each revise -- `Process: #35` |
| **the forward pass is a line** | a reversal is a ROW on the revise sheet at that boundary, not a re-run -- `Process: #36` |
| **one root per stage** | a `source` citing a page an earlier stage edited must read that page's current text |
| **one mechanism, four uses** | the pull feeds the next stage, the revise step, 7a, and runs `prove_unchanged` every time |
| **the run terminates** | two rounds per place, then the copy chief -- `Process: #9` |
