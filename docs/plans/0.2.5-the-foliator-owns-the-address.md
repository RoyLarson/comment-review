# 0.2.5 -- the foliator owns the address

**Branch `fix/folio-placement-is-not-where-the-anchor-is`. The release is the FOLIATOR: one walk
that emits every address and the anchor it is attached to, owned by one module, so nothing else
computes a place.** 0.2.4 settled what an address IS. This settles who MAKES one.

! **This is a `docs/plans/` plan, not a `docs/superpowers/plans/` one.** A superpowers plan is
written for an engineer with no context -- exact files, TDD steps, a commit per task. This is a
release scope: what ships, what does not, and what must be true first.

! **A PLAN is not a TODO.** Todos remain open indefinitely and progress as we see fit; a plan is a
scope of work to be completed in one run. Anything here that does not get done is filed in
`TODO/` before this plan closes, or it is lost.

## Phase 1 -- the foliator is a thing, not an expression

- [ ] **F1 -- three foliators, as closures or classes, each holding its own foliation AND its
      anchors.** Roy, 2026-08-19: *"fix the foliators making them either closures or classes that
      hold both the foliation and anchors"* and *"a b and c all get foliators."* None is one
      today: `a` reads `paragraph.get("declares")`, `b` is `sum(1 for n in code if n < at) + 1`,
      `c` is `code.index(start) + 1`. Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

- [ ] **F2 -- the walk is initialised at `<module>` and rolls forward.** `b0` is emitted at that
      trigger unconditionally; front matter OCCUPIES it the way a docstring occupies `a0`. Verify:
      `b0` and `b1` both exist on a file with no licence header, which is the measurement that
      opened this -- five file shapes, `b0` XOR `b1` on every one. Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

- [ ] **F3 -- no folio is computed from a line number.** `gap_step` and `on_step` stop doing
      arithmetic over `code`. Line order drives the WALK; it never computes the NUMBER. Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

- [ ] **F4 -- the emitted table is `address -> anchor`, recorded by the walk.**
      `census.anchor_every_address()` is deleted with its `beside` map and its `FRONT_MATTER`
      special case: the walk knows the anchor at the moment it emits the address. Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

- [ ] * **F5 -- RULING: the closing trigger.** Seven lines of code need nine `b` places -- `b0`
      at the module, `b1..b7` above each line, and one for the gap AFTER the last. Is that the
      module again, an explicit EOF trigger, or does `b` emit N+1 per walk? Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

- [ ] **F6 -- the test holds the PROPERTY, not the punctuation.**
      `test_a_folio_is_never_DERIVED_from_another` forbids two f-string forms and both
      expressions survive verbatim with `+ 1` appended. Replace with: every folio came from a walk
      that emitted it. Works [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md).

## Phase 2 -- one module makes an address

- [ ] **A1 -- the addresser is the ONLY place an address is made**, in both directions: the
      foliator assigns the foliation, and the addresser answers *which address does this line
      belong to right now*. Roy: that second half *"helps the agents understand what they are
      looking at right now in the code -- they need to search it anyway."* Works
      [`census-owns-addressing`](../../TODO/census-owns-addressing.md).

- [ ] **A2 -- the census stops setting anchors.** Five sites do today, two of them writing
      `getattr(node, "name", "<module>")` -- the NAME -- which a later pass overwrites. Works
      [`census-owns-addressing`](../../TODO/census-owns-addressing.md).

- [ ] **A3 -- each of the four modules announces ONE subject**: `addresser` names places, `page`
      says what a page and a paragraph are, `census` says which prose occupies which address,
      `galley` sets the proposed text. Verify by running `module-context` over all four. Works
      [`census-owns-addressing`](../../TODO/census-owns-addressing.md).

- [ ] **A4 -- the galley applies edits BY SERIES, never by line.** `b0`, then `a0`, then
      a -> b -> c. `splice` sorts on `(start, end, column, replacement)` and applies descending by
      line, which is what makes an `a`/`b` tie fall to the reviewer's quote style. Works
      [`b-foliator-uninitialised`](../../TODO/b-foliator-uninitialised.md) and closes
      [`galley-is-still-index-keyed`](../../TODO/galley-is-still-index-keyed.md).
