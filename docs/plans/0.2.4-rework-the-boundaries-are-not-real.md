## The steps

- [x] **P1 -- `src/comment_review/` holds the nineteen shipped Python files.** Imports by
      the package's own name, no path shims. Verify: no `sys.path.insert` anywhere in the
      package. ! All nineteen tracked as RENAMES; 61 import lines rewritten.

      !! **THEY WERE RELATIVE FIRST, AND THAT WAS WRONG.** Roy, 2026-08-24: *"If there are
      appropriate `__init__` files you should not need relative imports i would think."* !
      `__init__.py` is not what enables it -- it makes a directory a package, which both
      styles need; what makes an absolute import resolve is the package's parent being on
      `sys.path`, which the launcher guarantees in both trees. **The reason to switch is
      MEASURED:** relative imports carry arithmetic, and it was wrong TWICE in ten minutes --
      a rewrite rebuilt one from `node.module` alone, which holds no dots because `ast` keeps
      them in `node.level`, and the repair then wrote three where two belonged. An absolute
      import has no arithmetic to get wrong. 76 converted.
