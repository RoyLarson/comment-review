## Objective

Human-review questions are refused before any fold, including proof --copy;
committed editorial records have no human-held lifecycle, and one report
contract owns admission and fold events.

## Design, scope and dependencies

Parent: 0.2.4-the-middle-rebuilt. Branch:
feat/r2-human-questions-before-the-fold, based on completed R3 at 8973a0fd.
Specification: docs/reviews/2026-09-30-r2-r3.md, R2-A through R2-C. Processes
197 and 198 govern human admission; Process 207 governs imports.

Seal flows/transcribe.docket_of(copy: EditCopy, repo: Path) -> Docket using
flows/human.queries_in_copies(copies: list[EditCopy]) -> list[HumanQuery]. Raise
CannotTranscribe with every role, address and actual query before Fold or docket
construction. A human answer elsewhere never authorizes transcribing an
unreplaced query. Ordinary outside-my-role and unable-to-determine deferrals
remain valid.

Then remove State.UNSETTLABLE, Placement.HELD, the human-held asking fields and
serialized lifecycle, HeldMove and Unsettlable events, and their evaluator,
fold, command and transcription consumers. Preserve the mark/answer classifiers
required for pre-fold admission, including R3 subject-specific HUMAN_QUERY
effects. Direct evaluator/fold inputs containing human queries must refuse
visibly rather than settle or silently abstain. Preserve TO_COME, ordinary
open/contested placement, refusal, carry, acceptance and deferral behavior.

Reject old serialized human-held proofs by name, state and address on read; no
migration or silent reinterpretation. Supersede final-review T25 against the
state-removal work commit. Inspect human-questions T5 against the current
_open_moves refusal: retain refusal of genuinely undecided placement; supersede
an obsolete human-held-only deletion claim rather than delete that required
guard.

Move the remaining event definitions and Event union from desk/work/events.py
into pure desk/report.py. It may import desk/proof types and the standard
library, never flows or machine. Fold, bus and command renderers consume this
one contract; remove the old module and migrate live imports and vocabulary.
Preserve remaining event fields and messages, except obsolete human-held output.
Alternative assessed: retaining admission events under work leaves a false
ownership boundary; a new generic bus or rollback redesign is unnecessary.

Execution units: P1-P4 seal copy transcription; P5-P13 remove and verify the
lifecycle, command readers and obsolete goals; P14-P18 relocate and verify the
report contract; P19-P26 align documentation, run gates and review. Event
relocation follows state removal and command cleanup. P numbers identify tasks,
not execution order.

Python 3.11, shipped standard library only, uv run for all Python/tests/gates,
CRLF and ASCII file guidance. Edit src; plugins is assembled at release. No
release, agent-remit changes, chief-copy repair, answer-payload ruling,
machine-I/O relocation, rollback-producer redesign or unrelated backlog repair.
Documentation changes require exact author-approved wording; shared vocabulary
follows docs/conventions.md.

At each implementation unit: demonstrate required regressions, implement,
verify, commit work, finish every owning TODO/P with that commit, refresh
parents and commit closure before the next unit. Do not close a goal merely
because its dependent design was decided. Implementation begins only after Roy
reviews this concrete plan.
